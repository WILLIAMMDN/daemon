# Estados Documentales Permitidos
- `canonical`: Fuente oficial única de una decisión.
- `active`: Documentación en uso actual (no excluyente).
- `draft`: Borrador, no apto para implementar.
- `superseded`: Sustituido, debe apuntar al nuevo documento.
- `archived`: Histórico, no debe leerse por defecto.
- `obsolete`: Ya no aplica.
